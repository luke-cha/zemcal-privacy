# ZemCal Privacy Policy

This repository contains only the public privacy policy page for ZemCal. It does not contain the ZemCal source code.

After enabling GitHub Pages for this repository from **Settings → Pages → Deploy from a branch → main / root**, the page will be available at:

```text
https://luke-cha.github.io/zemcal-privacy/
```

Use that URL as ZemCal's App Store Connect Privacy Policy URL.
